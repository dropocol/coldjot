## Process

The `__tests__/characterization/` directory is **deleted** once the [Feature → test mapping](./README.md#feature--test-mapping) confirms every Phase 0 row has permanent coverage in the new suite.

1. For each of the 15 characterization files (Groups A–O), walk the mapping and confirm the permanent test exists and passes.
2. Delete the characterization file.
3. **If any row is not yet covered by a permanent test, do not delete that characterization file** — write the permanent test first, then delete.
