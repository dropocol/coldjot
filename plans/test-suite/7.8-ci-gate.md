# 7.8 — CI gate + coverage enforcement

> **Goal:** split test scripts, wire into turbo + CI, enforce the coverage gate.
>
> **Depends on:** [7.1](./7.1-repository-fakes.md)–[7.7](./7.7-integration-tests.md) all in place. **Feeds:** 7.9.

## What to do

### 1. Split test scripts in `apps/mailops/package.json`

- `"test"` — unit + adapters + processors (fast, no DB). Target <30s.
- `"test:integration"` — repository + integration tests (slow, needs DB).

Vitest projects config (or two config files) separates them. Keep `"test:watch"` + `"test:coverage"` working.

### 2. Wire turbo

Root `turbo.json`: add a `test` task.

```json
"test": {
  "dependsOn": ["^build:dev"],
  "outputs": []
}
```

Root `package.json`: `"test": "turbo run test"`.

### 3. GitHub Action

Add (or extend) `.github/workflows/ci.yml`:
- Boots a Postgres service container.
- Runs Prisma migrations against it.
- Runs `test` on every push; `test:integration` on PRs.
- Wires `DATABASE_URL_TEST` + secrets via GitHub Actions secrets (never commit them).

### 4. Coverage gate

Add `vitest --coverage` to CI. **Fail if** any file under `apps/mailops/src/{services,lib,controllers,adapters,repositories}` drops below the targets in the [README coverage table](./README.md#coverage-targets-by-layer). Pure helpers (`pixel.ts`, `link-wrap.ts`, `stats.ts`, `placeholders.ts`, `email-subject.ts`, `schedule/*`) target 100%.

Coverage config lives in `apps/mailops/vitest.config.ts` (already has `coverage.provider: "v8"` + include/exclude — extend with the thresholds).

## Files

**Modify:**
- `apps/mailops/package.json` (test scripts split)
- `apps/mailops/vitest.config.ts` (coverage thresholds; project split if using vitest projects)
- `turbo.json` (add `test` task)
- Root `package.json` (`test` script)
- `.github/workflows/ci.yml` (test + integration + coverage)

## Definition of done

- [ ] `npm run test` from root runs unit/adapter/processor tests across packages via turbo; exits 0.
- [ ] `npm run test:integration -w mailops` runs repository + integration tests; exits 0.
- [ ] CI runs `test` on push, `test:integration` on PR, coverage gate enforced.
- [ ] `npm run test -w mailops` runs in <30s without a DB.
- [ ] Coverage gate fails the build if any layer drops below its target.
